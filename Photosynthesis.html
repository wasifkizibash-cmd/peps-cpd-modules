Think like a scientist: If you increase light but the rate stops increasing, another factor has become limiting. Try changing only one variable at a time.

Suggested investigation

  1. Set carbon dioxide and water to 70%.
  2. Change only light intensity.
  3. Record at least five results using Record result.
  4. Repeat with carbon dioxide as the independent variable.
  5. Compare the patterns and identify where another factor becomes limiting.

Key idea: photosynthesis uses light energy, carbon dioxide and water to produce glucose and oxygen. The simulation models the rate using the least available of these three inputs.

Student challenge

1. What is the limiting factor when light = 20%, CO₂ = 80%, water = 80%?
2. If light is increased from 70% to 100% while CO₂ is only 30%, what should happen?
3. Why should a fair test change only one variable at a time?

Teacher notes

  • Suggested level: Year 8 / lower secondary science.
  • Core concept: limiting factors and input-output relationships in photosynthesis.
  • Variables: independent = selected environmental factor; dependent = modelled photosynthesis rate; controls = remaining factors.
  • Model limitation: this is a conceptual model, not a biological measurement. It deliberately uses relative percentages to make the limiting-factor relationship visible.
  • Extension: ask students to design a fair test, predict the shape of a graph, collect five or more data points and write a conclusion using evidence.
